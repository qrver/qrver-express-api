# Практическая работа №27

## Задание
- Разработайте руководство пользователя для вашего проекта.  
- Опишите, как пользоваться ключевыми функциями приложения: регистрация, авторизация, создание задач, уведомления и т.д.  
- Используйте понятные инструкции и скриншоты.  

## Цель работы
Научиться оформлять понятную и доступную пользовательскую документацию, которая поможет конечному пользователю работать с приложением без сторонней помощи.

## Пример проекта TaskManager
> «Мы создаём мобильное приложение TaskManager — оно помогает пользователю управлять личными и рабочими задачами. Чтобы пользователь мог освоить приложение без инструктора, нужно создать краткое и понятное руководство.»

## Структура документации

1. **Введение**  
   - Назначение приложения.  
   - Для кого предназначено (целевая аудитория).  

2. **Начало работы**  
   - Установка приложения.  
   - Регистрация пользователя.  
   - Вход в систему.  

3. **Основной функционал**  
   - Создание новой задачи.  
   - Установка сроков.  
   - Назначение приоритетов.  
   - Создание подзадач.  
   - Уведомления.  

4. **Дополнительно**  
   - Управление профилем.  
   - Настройки приложения.  

5. **Частые вопросы (FAQ)**  
   - Как изменить пароль?  
   - Как удалить задачу?  

## Пример user story

**User Story: Регистрация пользователя**  
> Как новый пользователь, я хочу зарегистрироваться в приложении, чтобы начать управлять своими задачами.

**Инструкция:**
1. Нажмите кнопку «Зарегистрироваться».  
2. Введите e-mail и пароль.  
3. Нажмите «Создать аккаунт».  

## Пример отчёта
> Создано руководство пользователя TaskManager. В документе описаны этапы регистрации, входа, добавления задач и настройки уведомлений. Каждый шаг снабжён скриншотом. Структура понятна для новых пользователей, в конце документа приведён раздел с часто задаваемыми вопросами.
