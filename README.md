# Express-JS-Pet

Это серверное приложение на Node.js с использованием Express и MongoDB, предназначенное для управления пользователями, постами и загрузкой файлов. Проект реализует базовые функции аутентификации, управления постами и загрузки изображений.

---

## Функциональные требования

1. **Регистрация и аутентификация пользователей**
    - Регистрация нового пользователя с email, паролем, именем и аватаром.
    - Вход пользователя по email и паролю.
    - Получение информации о текущем пользователе по JWT-токену.

2. **Управление постами**
    - Получение списка всех постов.
    - Получение одного поста по ID.
    - Создание нового поста (только для авторизованных пользователей).
        - Отправка уведомления в Telegram при создании поста.
    - Редактирование поста (только для авторизованных пользователей).
    - Удаление поста (только для авторизованных пользователей).

3. **Загрузка файлов**
    - Загрузка изображений (только для авторизованных пользователей).
    - Доступ к загруженным файлам по статическому маршруту.

---

## Нефункциональные требования

- Приложение должно работать на Node.js и Express.
- Для хранения данных используется MongoDB.
- Валидация входных данных реализована через express-validator.
- Пароли хранятся в зашифрованном виде (bcrypt).
- Для аутентификации используется JWT.
- Переменные окружения хранятся в `.env` файле.
- Приложение должно быть контейнеризированно и запускаться в Docker.

## Анализ требований и выявление противоречий

### Чек-лист

- **Полнота:** учтены основные сценарии (регистрация, логин, CRUD постов, загрузка файлов).
- **Последовательность:** нет противоречий между требованиями.

- Не реализована возможность восстановления пароля.
- Не реализована проверка прав на редактирование/удаление постов (только автор может изменять свой пост).

## Пример сценария использования

1. Пользователь регистрируется, указывая email, пароль, имя и (опционально) аватар.
2. Входит в систему, получает JWT-токен.
3. Создаёт новый пост, прикрепляет изображение.
4. Получает список всех постов.
5. Может редактировать или удалять только свои посты.
6. Может загружать и просматривать изображения.

## Запуск проекта

### Локально

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Создайте файл `.env` с переменными окружения (см. пример ниже).
3. Запустите сервер:
   ```bash
   npm start
   ```
   или в режиме разработки:
   ```bash
   npm run start:dev
   ```

### Docker

1. Установите Docker.
2. Создайте файл `.env` с переменными окружения (см. пример ниже).
3. Соберите образ:
   ```bash
   docker build -t express-js-pet .
   ```
4. Запустите контейнер:
   ```bash
   docker run --env-file .env -p 4444:4444 express-js-pet
   ```

## Используемые технологии

- **express** — минималистичный и гибкий фреймворк для Node.js, предназначенный для создания серверных приложений и API. В проекте используется для маршрутизации, обработки HTTP-запросов, middleware и организации архитектуры REST API.

- **mongoose** — объектно-документный модуль (ODM) для MongoDB и Node.js. Позволяет определять схемы данных, валидировать, преобразовывать и выполнять CRUD-операции с коллекциями MongoDB через удобный JavaScript-интерфейс. В проекте отвечает за взаимодействие с базой данных пользователей и постов.

- **dotenv** — библиотека для загрузки переменных окружения из файла `.env` в `process.env`. Это позволяет хранить чувствительные данные (секреты, пароли, настройки подключения) вне исходного кода и легко конфигурировать приложение для разных сред.

- **bcrypt** — криптографическая библиотека для безопасного хэширования паролей. Используется для создания стойких к взлому хэшей паролей пользователей и проверки введённых паролей при аутентификации.

- **jsonwebtoken** — инструмент для создания и проверки JWT (JSON Web Token). Применяется для генерации токенов при входе пользователя и последующей авторизации запросов к защищённым маршрутам. Позволяет реализовать stateless-аутентификацию.

- **express-validator** — набор middleware для валидации и санитации данных, поступающих в HTTP-запросах. Обеспечивает проверку корректности email, паролей, обязательных полей и предотвращает некорректные или вредоносные данные.

- **multer** — middleware для обработки multipart/form-data, используемого при загрузке файлов через формы. В проекте отвечает за приём и сохранение изображений пользователей и постов на сервере.

- **nodemon** — инструмент для автоматического перезапуска Node.js-приложения при изменениях в исходных файлах. Используется только в процессе разработки для ускорения тестирования и отладки.

- **node-fetch** — библиотека для выполнения HTTP-запросов в Node.js. Используется для интеграции с Telegram-ботом, отправки уведомлений и получения ответа.
